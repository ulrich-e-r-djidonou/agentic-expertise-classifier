Anthropic-aligned conversation assessment

Let the conversation show your level.

Invoke the skill after working with an agent. It evaluates the expertise you demonstrated in the current task, cites the evidence it used, and returns one of Anthropic's five levels or Unclear when no signal exists.

Use $assess-agentic-expertise to classify my task-specific expertise from this conversation.

How it works

No questionnaire. Only observed behavior.

The primary verdict uses the current conversation and the task at hand. Memory, when available, can add historical context but cannot change the session-level classification.

01

Work normally

Direct the agent on a real task. The skill does not need a special test or self-reported answers.

02

Invoke the skill

Ask for the assessment once the conversation contains enough framing, verification, or correction behavior.

03

Inspect the evidence

Review the exact behaviors used, contrary evidence, data sufficiency, and one practical next step.

Three co-equal signals

What the classifier actually looks for.

Setup specificity

Domain terms, non-obvious constraints, invariants, edge cases, conventions, and known failure modes.

Verification type

Targeted checks that reveal the user knows what could fail, rather than generic requests to double-check.

Direction of correction

Whether the user catches the agent's domain mistakes, or the agent must correct the user's mental model.

Not counted as expertise by itself

  • Job title or career seniority
  • Fluent or confident writing
  • Visible file names and paths
  • Generic requests to verify work
  • The difficulty of the task

Anthropic's scale

Task-specific, not person-wide.

A person can be expert in one task and beginner in another. The skill selects the closest holistic level, without averaging numerical sub-scores.

1 Novice

Generic framing, no targeted verification, and basic domain concepts supplied by the agent.

2 Beginner

Some correct terminology and obvious error detection, but important constraints and mental models remain incomplete.

3 Intermediate

Operationally precise direction with some targeted checks, but limited engagement with methodology and tradeoffs.

4 Advanced

Non-obvious domain constraints, specific verification, and successful redirection of at least one wrong approach.

5 Expert

Practitioner-level framing, tradeoffs, surgical checks, technically grounded correction, or targeted failure tests.

? Unclear

Reserved for conversations with no substantive signal of expertise. Sparse but meaningful framing still receives a level.

Example output

A verdict you can audit.

Task: Econometric model validation Evidence: sufficient
4 - Advanced Primary verdict based only on the current conversation.
Setup specificity, raises verdict

The user specified the expected coefficient signs, significance conditions, and the exact interpretation required for the model.

Verification type, raises verdict

The user requested checks aimed at a known failure mode rather than asking for a generic review.

Limiting evidence

No observed correction of a subtle domain error, so the conversation does not support an Expert classification.

Install

One skill folder. No backend.

Download the repository and place skill/assess-agentic-expertise in the skills directory used by your agentic coding tool.

Codex

Copy the skill folder into ~/.codex/skills/, then invoke $assess-agentic-expertise in a conversation.
