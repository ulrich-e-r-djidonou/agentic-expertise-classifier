# Assess Agentic Expertise

## Project

An installable skill that classifies task-specific expertise from observed behavior in an agentic coding conversation, plus a static public documentation page.

## Stack

- HTML5
- Embedded CSS
- Vanilla JavaScript
- Markdown skill instructions
- No backend
- No build step

## Deployment

- GitHub repository: `ulrich-e-r-djidonou/agentic-expertise-classifier`
- Deployment target: Netlify
- Publish file: `index.html`

## Product constraints

- One self-contained HTML file for the application
- Installable skill under `skill/assess-agentic-expertise`
- No questionnaire
- Anthropic-aligned labels from Novice to Expert, plus Unclear
- Primary verdict based only on the current conversation and task
- Memory used only as separate historical context
- Evidence displayed for every classification
- Mobile-friendly dark interface
- No emojis
- Clear independent-project disclaimer
- Accessible keyboard navigation and visible focus states
