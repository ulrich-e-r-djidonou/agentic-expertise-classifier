# Agentic Expertise Classifier

## Project

Single-page self-assessment that classifies how effectively a person works with agentic coding tools.

## Stack

- HTML5
- Embedded CSS
- Vanilla JavaScript
- No backend
- No build step

## Deployment

- GitHub repository: `ulrich-e-r-djidonou/agentic-expertise-classifier`
- Deployment target: Netlify
- Publish file: `index.html`

## Product constraints

- One self-contained HTML file for the application
- Eight behavioral questions
- Five expertise levels, from Novice to Expert
- Mobile-friendly dark interface
- No emojis
- Clean result layout suitable for screenshots
- Accessible keyboard navigation and visible focus states
