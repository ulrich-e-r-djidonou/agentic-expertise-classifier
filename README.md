# Agentic Expertise Classifier

A single-page behavioral self-assessment for people who work with agentic coding tools. It evaluates request framing and conversation behavior, then returns a five-level classification with practical guidance.

## Stack

Static HTML, embedded CSS, and vanilla JavaScript. No backend or build step.

## Deployment

Target: Netlify.

## Status

Initial project scaffold. Application implementation follows after the GitHub repository is created.
